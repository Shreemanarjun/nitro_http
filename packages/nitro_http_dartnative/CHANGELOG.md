## 0.0.8

* First release on dartpub.dev. Re-exports
  [nitro_http 0.0.8](https://pub.dev/packages/nitro_http/changelog) unchanged,
  plus its `dio` adapter as `package:nitro_http_dartnative/dio.dart`.
* Versions follow nitro_http: `nitro_http_dartnative` X.Y.Z depends on exactly
  `nitro_http` X.Y.Z.
